Retail SQL Analysis

SQL Mini Project | PostgreSQL

Project Overview

This project analyzes retail sales data using SQL. The project uses Orders, Customers and Products tables to analyze sales, customers, regions, categories and products.

Tables Used

  • Orders
  • Customers
  • Products

SQL Concepts Used

  • SELECT
  • JOIN
  • GROUP BY
  • HAVING
  • Aggregate Functions
  • Subqueries
  • CASE
  • CTE
  • Window Functions
  • RANK()

Day 1 – Basic SQL

SELECT * FROM Orders;
Use: Displays all records from the Orders table.

Day 2 – SQL Data Analysis

SELECT orderid, customerid, productid, quantity, sales
FROM Orders;
Use: Displays important order details for analysis.

Day 3 – Category-wise Sales

SELECT
    p.category,
    SUM(o.sales) AS TotalSales
FROM Orders o
JOIN Products p
ON o.productid = p.productid
GROUP BY p.category;
Use: Calculates total sales for each product category. 
SELECT
    p.category,
    COUNT(o.orderid) AS OrderCount
FROM Orders o
JOIN Products p
ON o.productid = p.productid
GROUP BY p.category
HAVING COUNT(o.orderid) > 20;
Use: Finds categories having more than 20 orders.

Day 4 – JOIN Operations

SELECT
    o.orderid,
    c.customername,
    c.region
FROM Orders o
INNER JOIN Customers c
ON o.customerid = c.customerid;
Use: Displays orders with matching customer details. 
SELECT
    c.customerid,
    c.customername,
    c.region
FROM Customers c
LEFT JOIN Orders o
ON c.customerid = o.customerid
WHERE o.orderid IS NULL;
Use: Finds customers who have never placed an order.

Day 5 – Subquery and CASE

SELECT orderid, sales
FROM Orders
WHERE sales > (
    SELECT AVG(sales)
    FROM Orders
);
Use: Finds orders having sales greater than average sales. 
SELECT
    orderid,
    sales,
    CASE
        WHEN sales >= 10000 THEN 'High Value'
        ELSE 'Regular'
    END AS OrderStatus
FROM Orders;
Use: Classifies orders as High Value or Regular.

Day 6 – CTE and Window Functions

WITH SalesByPerson AS (
    SELECT
        c.customername AS salesperson,
        SUM(o.sales) AS totalsales
    FROM Orders o
    INNER JOIN Customers c
    ON o.customerid = c.customerid
    GROUP BY c.customername
)

SELECT
    salesperson,
    totalsales,
    RANK() OVER (
        ORDER BY totalsales DESC
    ) AS salesrank
FROM SalesByPerson
ORDER BY salesrank;
Use: Calculates total sales and ranks customers. 
SELECT
    c.region,
    o.orderid,
    o.sales,

    SUM(o.sales) OVER (
        PARTITION BY c.region
        ORDER BY o.orderid
    ) AS runningtotal

FROM Orders o
INNER JOIN Customers c
ON o.customerid = c.customerid

ORDER BY c.region, o.orderid;
Use: Calculates running sales total for each region.

Day 7 – Retail SQL Mini Project

1. Main JOIN Analysis

SELECT
    o.orderid,
    o.orderdate,
    c.customername,
    c.region,
    p.productname,
    p.category,
    o.quantity,
    o.sales

FROM Orders o

INNER JOIN Customers c
ON o.customerid = c.customerid

INNER JOIN Products p
ON o.productid = p.productid;

2. KPI Analysis

SELECT
    SUM(sales) AS TotalSales,
    COUNT(orderid) AS TotalOrders,
    AVG(sales) AS AverageOrderValue,
    MAX(sales) AS HighestOrderValue
FROM Orders;

3. Sales by Region and Category

SELECT
    c.region,
    p.category,
    SUM(o.sales) AS TotalSales

FROM Orders o

INNER JOIN Customers c
ON o.customerid = c.customerid

INNER JOIN Products p
ON o.productid = p.productid

GROUP BY c.region, p.category

ORDER BY TotalSales DESC;

4. Monthly Sales

SELECT
    DATE_TRUNC('month', orderdate) AS Month,
    SUM(sales) AS TotalSales

FROM Orders

GROUP BY DATE_TRUNC('month', orderdate)

ORDER BY Month;

5. Top 5 Products

SELECT
    p.productname,
    SUM(o.sales) AS TotalSales

FROM Orders o

INNER JOIN Products p
ON o.productid = p.productid

GROUP BY p.productname

ORDER BY TotalSales DESC

LIMIT 5;

6. Top 5 Customers / Salespersons

SELECT
    c.customername AS Salesperson,
    SUM(o.sales) AS TotalSales

FROM Orders o

INNER JOIN Customers c
ON o.customerid = c.customerid

GROUP BY c.customername

ORDER BY TotalSales DESC

LIMIT 5;

Business Insights

  1. Overall sales performance can be measured using total sales and total orders.
  2. Regional analysis helps identify regions generating higher sales.
  3. Category analysis helps compare Electronics and Accessories sales.
  4. Top product analysis identifies products generating the highest sales.
  5. Monthly sales analysis helps understand sales trends over time.
